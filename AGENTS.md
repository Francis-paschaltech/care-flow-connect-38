# CareConnect Development Guidelines

## Project Understanding
- Understand the existing architecture before making changes.
- Analyze current components, dependencies, APIs, and database structure.

## Code Changes
- Preserve existing working features.
- Avoid rewriting large sections of the application unnecessarily.
- Reuse existing components and utilities.
- Follow current naming conventions and coding style.
- Keep changes modular and maintainable.

## UI/UX
- Maintain the existing design language.
- Ensure responsive behaviour across devices.
- Prioritize clean and accessible user interfaces.

## Development Workflow
- Make incremental changes.
- Check for errors before completing tasks.
- Avoid introducing unnecessary dependencies.
- Explain major file changes before implementing them.

## Project Goal
CareConnect is a healthcare-focused application. All improvements should prioritize reliability, usability, security, and a smooth user experience.
